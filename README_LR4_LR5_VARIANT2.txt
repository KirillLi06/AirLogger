ЛР4 и ЛР5 — вариант 2

Задание варианта 2:
выделить в лог-журнале все включения, произошедшие при срабатывании метода StrintToNumber,
если исключение попало в заданный пользователем интервал времени.

Итоговая реализация:
1. Основная сигнатура варианта — StrintToNumber без учета регистра.
2. Фильтр выполняется по интервалу времени HH:mm:ss.
3. В ЛР4 доступен выбор и ручной ввод сигнатур; пользовательские сигнатуры сохраняются в ComboBox.
4. Каждая сигнатура получает отдельный цвет подсветки на основе SHA256-хеша текста сигнатуры.
5. В ЛР5 парсинг вынесен в DLL: StrintToNumberRegexParser, DateRegexParser, ExceptionRegexParser, FormNameRegexParser.
6. Асинхронный режим использует Task/Task.WhenAll/Parallel.
7. Обычный режим использует Regex, Match, NextMatch.
8. Для графика используется отдельная форма Lab5ChartForm на GDI+.
